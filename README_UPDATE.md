# Обновление сайта Strategic Technology — многостраничная версия

## Что нового по сравнению со старой версией

1. **Сайт стал многостраничным** (как у pro-security.kz):
   - `index.html` — главная
   - `ops.html` — охранно-пожарная сигнализация
   - `tushenie.html` — системы пожаротушения
   - `video.html` — видеонаблюдение
   - `skud.html` — СКУД
   - `portfolio.html` — портфолио
   - `contacts.html` — контакты

2. **Квиз-калькулятор** на главной (`#quiz`): 6 вопросов → заявка
   уходит в WhatsApp на +7 701 715 42 86 с заполненной анкетой.
   Номер можно поменять в `script.js`, переменная `WA_NUMBER`.

3. **Блоки решений** с табами «Для бизнеса / Для дома».

4. **Логотипы клиентов** — пока плейсхолдеры. Положи логотипы в
   `images/clients/` и замени блоки в `index.html` (там есть комментарий с примером).

5. **Отзывы** — пока плейсхолдеры. ОБЯЗАТЕЛЬНО замени на реальные отзывы
   из 2ГИС перед публикацией (выдуманные публиковать нельзя).
   Также замени `#` в кнопке «Все отзывы в 2ГИС» на ссылку на вашу карточку.

6. **Блок «4 проблемы рынка»** — как у конкурента, но с вашим ответом.

7. В шапке появилось **выпадающее меню «Услуги»**.

## Как установить

Скопируй все файлы в папку проекта, заменив старые:
- `index.html` (заменить)
- `style.css` (заменить — старые стили сохранены, новые добавлены в конец)
- `script.js` (заменить — старый код сохранён)
- Новые: `ops.html`, `tushenie.html`, `video.html`, `skud.html`,
  `portfolio.html`, `contacts.html`, плюс этот README.

Потом коммит:
```
git add .
git commit -m "Многостраничная версия: квиз, решения, отзывы, страницы услуг"
git push
```

## Не забудь (как и раньше)

- Заменить `YOUR_FORM_ID` на свой ID из formspree.io (теперь форма есть на каждой странице)
- Создать `privacy.html` (на него ссылаются формы)
- Обновить `sitemap.xml` — добавить новые страницы
